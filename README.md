# Palworld Expedition Assistant

Небольшой Windows-помощник для автоматического запуска и завершения экспедиций в одиночной игре Palworld.

## Первая тестовая версия

Сейчас поддерживается только **«Пещера на равнине»** и конфигурация:

- экран `1920×1080`;
- масштаб Windows `100%`;
- Palworld в режиме **«окно без рамки»**;
- русский интерфейс игры;
- персонаж стоит перед Центром экспедиций, на экране видна подсказка взаимодействия `F`.

Программа сама:

1. открывает Центр экспедиций;
2. выбирает первую экспедицию;
3. нажимает **«Авто»** и **«Начать»**;
4. скрыто переключает Windows на часовой пояс Афин;
5. возвращает исходный часовой пояс;
6. забирает награду;
7. повторяет цикл заданное количество раз.

Исходный часовой пояс запоминается перед запуском и восстанавливается при аварийном завершении.

## Горячие клавиши

1. Один раз настрой экспедицию и число повторений в программе.
2. Оставь программу запущенной и вернись в Palworld.
3. Встань перед Центром экспедиций и нажми **F6**.
4. Для аварийной остановки нажми **F8**.

Окно программы открывать повторно не требуется. F6 и F8 перехватываются помощником и не передаются игре.

## Запуск из исходников

1. Установи Python 3.11.
2. Запусти `install.bat`.
3. После установки запускай `run_venv.bat`.
4. Windows запросит права администратора — они нужны для глобальных горячих клавиш и смены часового пояса.

## Готовый EXE

GitHub Actions собирает `.exe` после каждого push в `main`.

Открой вкладку **Actions** → последний запуск **Build Windows EXE** → скачай артефакт `PalworldExpeditionAssistant-windows`.

## Перед тестом

- выбери `1` повторение;
- освободи место и запас переносимого веса в инвентаре;
- не двигай мышь во время работы;
- дополнительная защита: резко перемести курсор в любой угол экрана.

## Как устроено наведение

Программа больше не использует абсолютные координаты рабочего стола. Точки пересчитываются относительно найденного окна Palworld, поэтому положение окна не должно влиять на клики.

Интерфейс Palworld отрисовывается движком игры и не виден обычной Windows UI Automation. Следующий более устойчивый вариант — распознавание кнопок по изображениям; для него будут добавлены эталонные фрагменты экранов.
